Crear Bot
Cómo crear un bot 🤖
Paso a paso — desde cero hasta que el bot está listo y funcionando.
1
Abre el formulario
Ve a form.html — ya sea tú o el cliente directamente. Este formulario tiene 7 secciones que se llenan en orden.
2
Llena los datos del negocio
Nombre del negocio, tipo (barbería, restaurante, clínica...), ciudad, descripción corta, teléfono, WhatsApp, redes sociales.
3
Elige el diseño
Colores de marca, logo (opcional), imagen de fondo. Si no tiene logo no importa — el bot igual queda profesional.
4
Agrega los servicios
Hasta 8 servicios con nombre, descripción y precio. Estos aparecen en la landing page y el bot los menciona cuando alguien pregunta.
5
Agrega la API Key de OpenAI
Para que el bot responda con IA necesita una API Key de OpenAI. El cliente la consigue en platform.openai.com — es gratis para empezar.
6
Envía el formulario
La IA procesa todo y genera el bot, la landing page y la tarjeta digital automáticamente. Tarda unos segundos.
7
¡Listo! El cliente recibe su BOT ID
Se genera un ID único (ej: SB007-X7Y8Z9). Con ese ID se accede al bot, la landing y la tarjeta. En modo GRATIS están en demo. Con PRO se activan públicamente.

Problemas
Si algo falla — qué hacer 🔧
Guía de solución rápida. La mayoría de problemas tienen solución en 2 minutos.
El bot no responde
Casi siempre es la API Key de OpenAI. Se acabaron los créditos o la key es inválida.
1
Ve al dashboard y busca el bot en cuestión
2
Verifica que el estado de OpenAI esté verde
3
Si está rojo: el cliente necesita recargar en platform.openai.com/settings/billing
WhatsApp no responde
El worker de Twilio puede estar caído o el número de Twilio no está configurado.
Revisa: dashboard.html → Estado de Servicios → Cloudflare WA. Si está rojo, revisa en twilio.com/console que el número esté activo.
Twilio Console
La página carga pero no muestra datos
Firebase no está respondiendo o hay un problema de permisos.
Revisa: console.firebase.google.com → proyecto super-bot-007 → Firestore → Rules. Las reglas deben permitir lectura.
Firebase Console
El link de GitHub no carga
GitHub Pages a veces tarda hasta 5 minutos en actualizar después de un push.
Solución: Espera 5 minutos y recarga con Ctrl+Shift+R. Si sigue sin cargar, revisa github.com/apolo189/superbot007/actions para ver si el deploy falló.
